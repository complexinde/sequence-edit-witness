# SequenceEditWitness design and test plan

AI-assisted independent prototype. Original synthetic public-text examples are local HTTP mocks only; no live source/publication/deployment is claimed. Purpose is an optimal exact line-edit witness for bounded non-personal text snapshots, not semantic equivalence or code review.

Zero-argument constructor fixes owner. Owner `register(edit_id,left_url,left_sha256,right_url,right_sha256)` locks source pair and unused ASCII ID; max8 lifetime pairs. Each URL is exact commit-pinned public raw.githubusercontent.com with safe ASCII segments, hash64 lowercase hex. Each source0..8192 bytes, strict UTF8, <=64 LF-split elements. Empty bytes map to[]; every other text uses `text.split("\n")`, retaining final empty element and literal CR characters. Join byLF exactly reconstructs original bytes. No Unicode/newline/whitespace normalization. Registration does not assert source validity.

Anyone `certify(edit_id,expected_revision)` at REGISTERED0 fresh-fetches both exact byte hashes and independently derives full result. Suffix dynamic programming gives unit Levenshtein optimum: identical MATCH0, REPLACE/DELETE/INSERT1. At every cursor choose first optimal operation in MATCH,REPLACE,DELETE,INSERT priority. Include MATCH operations, cursor indices and exact old/new/text values in complete applicable script. Independently check script shape, indices, consumption, cost and application exactly reconstruct target UTF8 bytes. Validator performs fresh source fetch/hash/lineparse/full DP/script/replay and compares entire canonical bound result; leader shape, self-reported cost or target hash alone cannot pass. Binding covers protocol/chain/contract/owner/editID/both URLs+hashes/registeredAt/expectedRevision/certifier/certifiedAt.

Owner `activate(edit_id,expected_revision,certificate_id)` at CERTIFIED1 accepts exact historical receipt ACTIVE2; no refetch/availability monitoring. Owner `revoke(edit_id,expected_revision,reason)` from any nonterminal phase irreversibly withdraws. IDs/sources never reset; max4 phase events, lifetime capacity never recycles. `get_edit`, `is_active(edit_id,certificate_id,expected_revision)`, `get_configuration`. A consumer must read current status/revision/certificate plus complete source pair and script, not cache past ACTIVE. No real identity, authorization, semantic equivalence, safe patch execution or assets claimed.

Test plan before implementation: real deployed minimal-contract missing-API red evidence; literal replacement+MATCH scripts, empty/insert/delete, trailingLF vs missingLF, CRLF vsLF and Unicode exactness, repeated lines and multiple optimum tie choices; independently apply literal expected script in tests without host DP substitute; forge full-shaped cost/script/source lines and reject validator, changed/unavailable/wrong-hash/invalidUTF8/oversized/65elements; bound valid64lines/8192bytes, owner/CAS/certid/domain/terminal/history/capacity; full exact GenVM0.2.12 actual direct suite + semantic lint/schema/0ctor. Preserve genuine red and green logs. Package safe self-contained prototype, no browser/wallet/external writes.
